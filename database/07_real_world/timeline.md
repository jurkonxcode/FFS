# Real World Timeline

Timeline dunia nyata dari 1996 sampai 2026.

---

## Table: real_world_timeline

| Field | Type | Description |
|---|---|---|
| timeline_id | UUID | ID timeline |
| year | INTEGER | Tahun |
| start_date | DATETIME | Awal tahun |
| end_date | DATETIME | Akhir tahun |
| status | STRING | Status data |
| created_at | DATETIME | Dibuat |
| updated_at | DATETIME | Diubah |
