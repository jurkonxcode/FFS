# Real World Technology

Menyimpan perkembangan teknologi dunia nyata.

---

## Table: real_world_technologies

| Field | Type | Description |
|---|---|---|
| technology_id | UUID | ID |
| name | STRING | Nama teknologi |
| category | STRING | Kategori |
| invented_at | DATETIME | Ditemukan |
| introduced_at | DATETIME | Diperkenalkan |
| mass_adoption_at | DATETIME | Mulai digunakan luas |
| status | STRING | Status |
| source_id | UUID | Sumber |
